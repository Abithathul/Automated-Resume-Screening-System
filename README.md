# Automated-Resume-Screening-System


**PROJECT OVERVIEW**

The Automated Resume Screening System is an AI-based application developed to simplify and automate the recruitment process. The system analyzes resumes using Natural Language Processing (NLP) and Machine Learning techniques to identify suitable candidates based on skills and resume content.

This project helps reduce manual screening effort and improves the efficiency of candidate shortlisting for recruiters and organizations.


**FEATURES**
Upload and analyze resumes automatically
Extract important keywords and skills from resumes
Resume classification using Machine Learning
Candidate shortlisting based on matching criteria
NLP-based text processing
User-friendly interface for recruiters
Faster and more efficient hiring support
