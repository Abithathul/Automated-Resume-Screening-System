# Automated-Resume-Screening-System

**PROJECT OVERVIEW**

The Automated Resume Screening System is an AI-based web application developed to simplify and automate the recruitment process. The system analyzes resumes using Natural Language Processing (NLP) and Machine Learning techniques to identify suitable candidates based on skills, qualifications, and resume content.

This project helps reduce manual screening effort and improves the efficiency of candidate shortlisting for recruiters and organizations. Additionally, the system includes an intelligent chatbot for user assistance and a job portal module for managing job postings and applications.

**FEATURES**
Upload and analyze resumes automatically
Extract important keywords and skills from resumes
Resume classification using Machine Learning
Candidate shortlisting based on matching criteria
NLP-based text processing
User-friendly interface for recruiters
Faster and more efficient hiring support
AI-powered chatbot for candidate interaction and query support
Job portal module for posting and managing job openings
Applicant tracking and job application management
Real-time resume matching with job requirements
Secure and organized candidate data management
